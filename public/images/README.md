# Screenshots and Profile Pictures

This directory should contain the following images:

## Website Screenshots
- `halvex-screenshot.png` - Screenshot of the Halvex website
- `syndia-screenshot.png` - Screenshot of the Syndia project

## Profile Pictures
- `linkedin-profile.jpg` - Your LinkedIn profile picture
- `github-profile.jpg` - Your GitHub profile picture
- `instagram-profile.jpg` - Your Instagram profile picture

## How to add screenshots

1. Take screenshots of the websites you want to show in tooltips
2. Save them in this directory with descriptive names
3. Update the image paths in `app/page.tsx` or `app/images.ts`

For profile pictures, use square images for best results as they will be displayed in a circular format.
